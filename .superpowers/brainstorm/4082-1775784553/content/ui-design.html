UI Decisions

1

Narration grouped by purpose

Agent status messages grouped under their purpose (Overview, Research, Build) with a colored left border. Messages stream in as agents work. Keeps the chat tidy while showing parallel progress.

2

Narration as flat stream

Agent status messages appear as individual lines in chronological order, like the Claude Haiku screenshot. Simpler, but interleaved purposes might be confusing during parallel work.

3

Info button opens sheet with full graph

Tapping (i) opens a sheet showing the complete task graph — each node, its tool calls, raw results, timing, and status. Full transparency for power users.

4

Info button expands inline

Tapping (i) expands the message in-place to show the log entries below the stitched response. Less disruptive but takes up chat space.
