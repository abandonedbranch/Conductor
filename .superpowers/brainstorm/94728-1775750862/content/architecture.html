Data Flow

1. User provides URL in chat
2. WebReaderTool validates URL, calls WebReaderService.read(url)
3. Service updates WebReaderState → .loading(url)
4. WebReaderHost mounts WKWebView, begins navigation
5. Page loads → service runs fixed JS: document.body.innerText
6. Service updates state → .success(title, text)
7. Host unmounts WKWebView, loading card dismisses
8. Extracted text returned to chat context
